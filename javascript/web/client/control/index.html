Processors

The processors the orchestrator can use. Badges show tokenization support (Specific = processor-specific tokenization; Agnostic only = raw path only) and credential status. Use 🔑 to add a processor’s keys, and Remove / Add to bring processors in and out one at a time. A processor in use by a routing rule or the fallback can’t be removed until the plan is updated. Changes are runtime-only (put keys in .env to persist); the store reflects them on its next load.
